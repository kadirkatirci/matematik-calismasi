# Matematik Çalışması Dijital Aracı

Ünite 2 öğretmen eğitimi çalışmalarında, 2 × n birim kareden oluşan dikdörtgene ilişkin yanıtları kaydetmek ve incelemek için hazırlanmıştır. Sayısal yanıtlar ile genel bağıntıların dağılımını ve eksik yanıtları gösterir. Açıklamaları öğretmen değerlendirir; araç otomatik puan üretmez.

## Kullanım

1. [Matematik Çalışması Dijital Aracı](https://kadirkatirci.github.io/matematik-calismasi/) bağlantısını açın. Çevrimiçi erişim için internet gerekir. Çevrimdışı kullanım için `index.html` dosyasını indirip tarayıcınızda açın.
2. **6 kurmaca örneği yükle** ile örnekleri inceleyin; kendi çalışmanız için kimliksiz bir deneme koduyla yeni satır ekleyin.
3. Yanıt tablosunu ve kaynaklara göre ayrı özetleri karşılaştırın. Dar ekranda yanıt tablosunu sağa ve sola kaydırabilirsiniz.
4. Sayfayı yenilemeden veya kapatmadan önce **JSON kaydet** düğmesini kullanın ve dosyanın indiğini kontrol edin. Çalışmaya devam etmek için **JSON geri yükle** ile bu dosyayı açın.
5. Yanıtları tablo olarak kullanmak için **CSV indir** düğmesini seçin. **CSV içe al**, bu aracın oluşturduğu CSV dosyalarını okur. İşlem geçmişi JSON dosyasında korunur.

## Çalışmanızı saklama

Yanıtlar açık sayfanın belleğinde tutulur; sunucuya gönderilmez. Kalıcı çalışma kopyanız, indirdiğiniz JSON dosyasıdır. Sayfayı yenilemek bellekteki çalışmayı siler. İçe alma mevcut çalışmanın yerini alacağı için önce onay ister.

Yalnız kimliksiz, kurmaca eğitim denemeleri kullanın; gerçek öğrenci adı veya kişisel bilgi girmeyin. Hesap gerekmez. İndirdiğiniz tek HTML dosyası internet bağlantısı olmadan da çalışır.
